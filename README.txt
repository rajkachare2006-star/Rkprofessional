RAJ KACHARE - PROFESSIONAL PORTFOLIO WEBSITE

HOW TO OPEN
1. Extract this ZIP file.
2. Open the extracted folder in VS Code.
3. Double-click index.html or open it in your browser.
4. To add your own photo, save the photo in the same folder as index.html with the exact name profile.jpg.
5. Save code changes with Ctrl+S and refresh the browser with Ctrl+R.

NOTE
The Restaurant Management System image is loaded from Unsplash online, so an internet connection is required to show it. Education entries do not include school names or years because these details were not provided. Please confirm the exact title of your current MIS role before publishing.
